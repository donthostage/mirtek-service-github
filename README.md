# Миртек: прототип сервиса обращений

Рабочий локальный API и демоинтерфейс. Версия 0.4 реализует исходящие HTTP-запросы к отдельному моку источника: наличие по артикулу и складу с отдельным резервом, правила возвратов и жалоб, расписание, акции и условия доставки. Нормализатор перед этим шлюзом может перевести другой контракт в наши поля. В режиме AITUNNEL используется семантический разбор намерения, вида вопроса и параметров с проверкой цитат и контекста. Сервис не подключён к компании. На предыдущей редакции получены первые живые ответы DeepSeek через AITUNNEL, а также таймауты и ошибка уточнения. Последняя редакция прошла живой прогон 10 учебных диалогов/12 шагов через DeepSeek; это открытые данные разработки, не приёмка компании. Реальные KPI не измерены.

Текущий объём — полностью на моках, без ожидания реальных инструкций. Первый количественный замер настоящей DeepSeek: 94,23% правильных решений, 97,37% точности ответов, 97,5% запросов до 5 секунд, 77,08% автоматизации (порог 80% в первом замере не пройден). Причины трёх ошибок исправлены. Три прогона после исправлений: суммарно 98,08% решений, 100% фактической точности, 98,36% запросов до 5 секунд, 81,25% автоматизации. Все объединённые пороги пройдены, но первый из трёх прогонов отдельно не прошёл автоматизацию из-за двух таймаутов. Это повторяемый синтетический набор, не независимая приёмка. Проверки кода: 218 тестов проходят. Подробности: [MOCK_ACCEPTANCE.md](docs/MOCK_ACCEPTANCE.md). Для согласования API: [CONTRACT_AGREEMENT.md](docs/CONTRACT_AGREEMENT.md).


Актуальные вопросы заказчику и подтверждённые решения — `docs/OPEN_QUESTIONS.md`. Сверка полного объёма PDF — `docs/REQUIREMENTS_AUDIT.md`; ограничения семантической проверки — `docs/SEMANTIC_PARSER.md`.

## Как теперь работает источник

Наш сервис сам спрашивает API источника и проверяет ответ. Он не ждёт, что компания пришлёт обновления. Для учебного наличия: артикул 10001 и склад WH-DEMO-1. Магазин не приравнивается к складу. Для возвратов и жалоб работает поток уточнения и чтения учебных инструкций.

Подробная инструкция, контракты и границы — `docs/HTTP_PULL.md`. Проект поведения — `docs/RETURNS_COMPLAINTS.md`; исполнимые схемы — `contracts/`. Минимум пять сценариев сохраняется для итогового проекта.

## Запуск

Требуется Python 3.12 (на нём проверено) и интернет для первой установки. Из папки проекта в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m scripts.run_demo
```

Открыть `http://127.0.0.1:8766`. Остановка: Ctrl+C в окне сервера. Авторизация и интеграции для локального демо не нужны. При занятых портах: `python -m scripts.run_demo --api-port 8866 --source-port 8867`; тогда интерфейс будет на `http://127.0.0.1:8866`.

После установки зависимостей можно запускать `./start-local.ps1`: он использует `.venv` из папки проекта и включает baseline без платных вызовов. `-ApiPort 8866 -SourcePort 8867` меняют порты. Скрипты не зависят от путей на компьютере автора. Архив содержит исходники, а не Python и сторонние пакеты.

## AITUNNEL

После установки зависимостей запустите `./start-aitunnel.ps1`: он запросит точный id модели и ключ скрытым вводом, затем запустит сервер. Если сервер baseline уже работает на 8766, сначала остановите его. Ключ не сохраняется в файлы. Модель выбирается пользователем из каталога AITUNNEL, обязательно с поддержкой JSON Schema; конкретная модель ещё не выбрана сравнением.

Для ручного запуска задайте серверные переменные `MIRTEK_CLASSIFIER=aitunnel`, `AITUNNEL_MODEL` и `AITUNNEL_API_KEY`, затем запустите `python -m scripts.run_demo` (поднимает сервис и мок источника). `.env.example` — справочный шаблон; автоматического чтения `.env` нет. Не вставляйте настоящий ключ в команды с историей, код или интерфейс браузера.

Если режим aitunnel выбран, но ключ/модель отсутствуют, API вернёт handoff с `model_not_configured`. При сбоях модели нет скрытого переключения на правила. `/health` показывает выбранный режим и наличие настройки, но не подтверждает доступность провайдера.

Модель возвращает направление, вид обращения, тему правила и явно указанные параметры с цитатами. Сервер проверяет цитаты, получает факты из источника и программно разрешает дату. Каталог, остатки и база знаний модели не передаются. В AITUNNEL уходит текущий текст и ограниченный структурированный контекст ожидаемого уточнения. По уточнению пользователя от 23.10.2026 использование AITUNNEL разрешено без дополнительных ограничений компании; реальные обращения пока не предоставлены.

Подробности: `docs/AITUNNEL.md`, `docs/SEMANTIC_PARSER.md`; подготовка сравнения — `docs/MODEL_COMPARISON.md`.

## Что проверить в интерфейсе

1. «До скольки сегодня работает магазин на Учебной?» → часы и источник.
2. «Как работает S1?» → часы на сегодня по учебному расписанию. Закрытие 23.10.2026 — исключение только этой даты. После 31.10.2026 дата расписания не подтверждена, сервис отказывается отвечать.
3. «Есть артикул 10001 WH-DEMO-1?» → доступно 12.5 м, в резерве 2.5 м; для WH-DEMO-2 — нулевой доступный остаток. Адрес магазина без идентификатора склада вызывает уточнение.
4. «Есть товар?» → артикул → склад: уточнения продолжаются через context_id.
5. «Как оформить возврат?» → канал покупки → учебная инструкция через API источника. «Как оставить жалобу?» → учебная инструкция. Конкретная жалоба → оператор.
6. «Хочу оператора», неизвестный вопрос, несколько сценариев → handoff с явным указанием, что доставки сотруднику нет.

Все магазины, артикулы, количества и политики вымышлены. В режиме HTTP остаток помечается synthetic и действует пять минут с момента ответа мока: у 10001 на WH-DEMO-1 доступно 12.5 м из 15 м, 2.5 м в резерве. Расписание, акции и тексты правил в том же моке подтверждены до 22.11.2026 09:00 UTC+7, а конкретная дата расписания — только 22–31 октября. Старый режим snapshot читает `data/synthetic.json` с теми же учебными сроками; его остатки действуют до 23.10.2026 09:00 UTC+7. После истечения сервис отказывается отвечать. Не продлевайте срок реальных данных без нового подтверждённого снимка.

## Ограничение времени ответа

У одной обработки общий бюджет внешних вызовов 4,5 секунды: модель и все последующие обращения к источнику делят оставшееся время. Отдельные пределы — 3,5 секунды для модели и 1 секунда для одного запроса источника. При исчерпании общего бюджета — `handoff` с `request_timeout`, без нового запроса и скрытого ответа из другого источника. Это программное ограничение ожидания; KPI «95% до 5 секунд» всё ещё требует измерения API под реальной нагрузкой, включая очередь и HTTP-накладные расходы.

## Диагностика AITUNNEL

При `model_timeout` смотрите `.runtime/aitunnel.log`: этап ожидания HTTP-заголовков/тела, статус HTTP и время. Текст обращений, ключи и ответы провайдера не записываются. Логи ротируются (64 КиБ, две резервные копии) и исключены из Git.

По умолчанию остаются строгие лимиты 3,5/4,5 секунды. Для диагностики можно задать `AITUNNEL_TIMEOUT_SECONDS=15` и `MIRTEK_REQUEST_TIMEOUT_SECONDS=18`. `/health` покажет `timing_profile=diagnostic` и фактические лимиты. Такой запуск не доказывает KPI до 5 секунд. `AITUNNEL_BASE_URL` допускает только основной адрес `https://api.aitunnel.ru/v1` и официальное зеркало `https://ru-api.aitunnel.ru/v1`; автоматического переключения и повторных запросов нет.

`AITUNNEL_REASONING_EFFORT` задаёт явный `reasoning.effort`: none/minimal/low/medium/high/xhigh/max. Если переменная не задана, параметр не отправляется. Поддержка значения зависит от модели; 400 не вызывает автоматической смены модели или повторного платного запроса. Режим `none` для deepseek-v4.1-flash-1017 подтверждён живыми замерами; `/health` и отчёты фиксируют настройку. В безопасном логе также видны известные finish_reason и численные счётчики токенов; текст рассуждений не сохраняется.

## Проверка исправленного потока

«Как оформить возврат?» → уточнение канала → «В магазине» → пошаговая инструкция из /source/v1/policies/resolve. Точный ответ одним из предложенных каналов при ожидаемом уточнении не требует новой генерации модели. Полный вопрос «Купил товар в магазине, хочу оформить возврат. Что нужно сделать?» читает ту же инструкцию. «Сколько стоит доставка?» читает /source/v1/delivery/terms, в отличие от запроса цены конкретной доставки по адресу. Учебный тариф от 300 ₽ и 1–3 рабочих дня вымышлены и не являются условиями Миртека. Требование выплаты, расследование фактической жалобы и неподтверждённые факты остаются за сотрудником.

Распознаватель повторно использует HTTP-соединения в пределах процесса. При остановке приложения пул закрывается. Общий дедлайн сохраняется отдельно для каждого обращения; ретраев и автоматической смены модели нет. Это оптимизация подключения, а не подтверждённое ускорение самого провайдера.

## Повторить живую проверку

После локального запуска AITUNNEL: `python -m scripts.check_live_api` покажет план без сети, `python -m scripts.check_live_api --run` проверит работающий API на 9876. Максимум 13 HTTP-запросов (12 шагов плюс возможное подтверждение графика магазина); запросы могут расходовать баланс провайдера. Ключ скрипт не читает, он остаётся в серверном процессе. Последний отчёт — docs/live-development-report.json, предыдущие неудачные прогоны сохранены рядом. Для другого порта задайте --api-url. Настоящие обращения/правила и независимая экспертная приёмка ещё нужны.

Для локальной разработки можно запустить `start-aitunnel.ps1 -Reload`: после ввода ключа код перезагружается без нового ввода. Перезагрузка сбрасывает незавершённые диалоги. Режим не используется при измерении производственной нагрузки.
