# Проверка проекта возвратов и жалоб

Дата: 23 октября 2026. Среда: Windows, bundled Python 3.12, зафиксированные зависимости проекта.

`python -m contracts.export` успешно сформировал три JSON Schema, OpenAPI источника и девять примеров. В примерах разбор задан вручную; модель их не создавала и не проверяла.

`python -m pytest -q`: 84 passed, 1 warning. Включает 71 существующую проверку и 13 проверок нового проекта контрактов. Проверены уточнение канала и ответ после него, отсутствие лишнего уточнения для общих правил, приоритет персонального случая перед общей инструкцией, сохранение двух сценариев, отсутствие источника, устаревший источник, несовпадение области действия, запрет мока в реальном режиме, предел уточнений, просьба оператора, валидация контрактов и HTTP-мок через TestClient. Предупреждение о будущей смене HTTP-клиента Starlette не блокирует текущие зафиксированные тесты.

Новый поток не подключён к app/main.py. Новый реальный LLM-разбор, интеграция с компанией, доставка оператору и KPI не проверены. HTTP-мок не создаёт жалоб и не выполняет возвраты. Ответы на общие вопросы показаны на явно вымышленных текстах, а не на правилах компании.
