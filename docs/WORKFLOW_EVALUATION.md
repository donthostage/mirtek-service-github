# Проверка актуальных диалогов

data/workflow-evaluation.json содержит 32 открытых синтетических диалога и 36 шагов по шести направлениям: возвраты, жалобы, наличие, расписание, акции, доставка/самовывоз. Помимо обычных ответов проверяются уточнения, личные решения, связанные намерения, неизвестные вопросы, выдуманные и частичные ID, неверный источник, устаревание, неопределённый/некорректный разбор и смена темы.

Каждый шаг содержит текст, вручную заданный model_output и независимо записанное ожидание: статус, сценарий, причина, нужный фрагмент ответа, id источника или сохранённые темы пакета оператору. model_output не получен от настоящей модели. Набор использовался при разработке, не является закрытым контролем и не доказывает понимание произвольных фраз.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_workflows
```

Команда подаёт записанные разборы через настоящий код адаптера AITUNNEL и его валидацию, вызывает клиентский API и HTTP-клиент источника через тестовые транспорты, а затем сравнивает фактический Reply с ожиданиями. Платных и внешних сетевых запросов нет. Время заморожено на 23.10.2026 12:00 UTC+7; источник складов получает это время через серверную dependency, которую клиент API изменить не может.

Полный отчёт — docs/workflow-report.json. Последний запуск: совпали 36 из 36 шагов. Это программная регрессия на моках, а не показатель 100% семантического качества, производительности или фактической приёмки компанией. Число replay-запросов модели в отчёте означает вызовы поддельного транспорта, не обращения к AITUNNEL.

Три вида доказательств разделены:

- scripts/evaluate.py — исторический лексический baseline на открытой выборке.
- scripts/evaluate_workflows.py — актуальная цепочка обработки с заранее заданным семантическим разбором.
- scripts/compare_models.py --run — будущие живые вызовы выбранных моделей; без --run это только безопасный план. Живое качество пока не проверено.

Качество на реальных обращениях, независимая разметка и пороги KPI проверяются отдельно по ACCEPTANCE.md. Маленький открытый набор не заменяет контрольную выборку компании.
