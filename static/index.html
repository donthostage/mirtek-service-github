Вопрос клиента → проверяемый ответ

Сервис выбирает сценарий, читает источник и возвращает ответ, уточнение или признак участия оператора.

Только синтетические данные. Магазины, товары и условия вымышлены. Проверяется выбранный режим распознавания… Подключения к компании нет. Наличие проверяется по артикулу и складу. В режиме HTTP нужен отдельный локальный мок источника; при его недоступности сервис передаст вопрос оператору.

Сообщение клиента

Ожидается уточнение. Следующее сообщение продолжит этот вопрос.

Учебные магазины: S1 — Учебная, 1; S2 — Примерная, 2.
Артикулы: 10001 — хлопок; 10002 — лён.
Учебные склады: WH-DEMO-1 и WH-DEMO-2. Магазин и склад — разные объекты.
